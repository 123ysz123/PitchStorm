# PitchStorm · 绿茵风暴

一个**单文件**的浏览器足球模拟游戏。纯 HTML + CSS + 原生 JavaScript + Canvas 2D，无框架、无构建步骤、无第三方依赖。

双击 `PitchStorm.html` 就能玩，也可以放到任意静态服务器上。

## 特性

- **完整比赛引擎**：22 名球员实时 AI、传球/射门力量条、方向性传球、二过一、铲球、门将出击、界外球/角球/球门球、伤停与体力
- **球队管理**：六项能力逐项调节、首发与替补互换、四种阵型、三项战术滑块，改动即时作用于比赛
- **赛事模式**：小组赛 + 淘汰赛，AI 对 AI 用泊松分布模拟比分，点球大战决胜
- **双端操作**：键盘（桌面）+ 虚拟摇杆与放射状按键（手机触屏）
- **自适应画质**：按实测帧时间自动升降渲染分辨率
- **文本存档**：可选的本地服务器把存档与战绩写成纯文本文件，无需登录

## 快速开始

### 方式一：直接打开（推荐）

双击 `PitchStorm.html`。存档写入浏览器 `localStorage`，功能完整，不需要服务器。

### 方式二：本地服务器（可选）

需要跨设备同步存档，或想用手机访问时：

```bash
python server.py 8080
```

Windows 下也可以双击 `启动内网服务.bat`。

然后用 `ipconfig` 查本机 IPv4，手机连同一 Wi-Fi 访问 `http://<你的IP>:8080/`。

> 首次运行 Windows 可能弹出防火墙提示，需要允许 Python 的专用/公用网络访问，否则手机会连不上。

## 操作

### 进攻（控球时）

| 按键 | 作用 |
| --- | --- |
| `↑↓←→` | 移动球员 |
| `W` | 冲刺（按住，消耗体力） |
| `S` | 地面传球（按住蓄力） |
| `A` | 高空长传（按住蓄力） |
| `D` | 射门（按住蓄力，松开射出） |
| `空格` | 二过一 |
| `E` | 过人（瞬间变向加速） |
| `Z` / `C` | 左旋 / 右旋 |

### 防守（无球时）

| 按键 | 作用 |
| --- | --- |
| `↑↓←→` | 移动球员 |
| `W` | 回追加速 |
| `D` | 抢断 / 压迫 |
| `A` | 铲球 |
| `S` | 切换到离球最近的球员 |
| `Q` | 门将出击 |
| `ESC` | 暂停 |
| `TAB` | 查看比赛数据 |

### 手机触屏

左下角虚拟摇杆控制方向，右下角放射状按键：射门、传球、长传、冲刺、二过一、换人、暂停、全屏。力量条逻辑与键盘完全一致——按住蓄力，松开释放。

## 存档

**本地存档**：`localStorage` 键 `pitchstorm_save_v1`，保存球员能力、首发名单、阵型、战术与赛事进度。

**服务端存档**（可选，需运行 `server.py`）：

```
data/devices/<设备码>.json   每台设备一份存档
data/matches.jsonl           每行一场比赛记录
```

设备识别优先级：Cookie `ps_dev` → 请求头 `X-Device-Id`（浏览器本地生成的随机码）→ IP 哈希。服务端每次响应都会种一年期 Cookie，清缓存后靠 Cookie 还能认回来。

`/data/*` 路径对外一律 404，其他人无法下载别人的存档。离线运行时前端自动降级为「仅本地」，不会报错。

## 技术实现

- **世界坐标** 1050 × 680 单位（约 1 单位 = 0.1 米），视口宽 960 单位，相机跟随球
- **固定步长主循环**：逻辑锁定 1/60 秒，物理不受刷新率影响；低帧率下用累加器补步
- **连续碰撞检测**：球按帧内扫过的线段判定是否碰到球员，避免高速球穿人
- **静态世界烘焙**：看台、观众、草皮、球门线一次性画进离屏画布，每帧只贴相机可见区域
- **球员精灵缓存**：身体、条纹、高光烘焙成位图，消掉每帧的渐变创建
- **自适应分辨率**：滚动平均帧时间超过阈值就降采样，回升有冷却防抖动
- **射门/传球误差模型**：按「落点横向偏差」建模再换算成角度，近距离自动收敛
- **AI 决策**：按位置权重计算跑位目标，逼抢者单独指定（不会占用玩家操控的球员）
- **音效**：Web Audio API 合成，噪声突发 + 正弦扫频，无音频文件
